Signal models#

Simulator is the base class of a pulse sequence protocol and the only model interface that estimators, reconstruction and sequence design consume.

A subclass names an operator for each kind of event (excitation, refocusing, inversion, saturation, readout, delay) and implements layout(), which returns the operators of one repetition in playing order. A protocol with a closed form implements evaluate() instead. The same operators interpret a description read by from_description() or from_pulseq(), in which case the layout is not called. The constructor takes the keywords simulate() takes, bind() fixes more on a copy, and a call overrides both. See Signal model.

class SSFPMRF(Simulator):
    excitation = Excitation
    inversion = Inversion
    readout = SSFPFidReadout
    states = 10

    def layout(self, *, flip, TR, TI=0.0):
        parts = [self.operators.inversion(duration_s=TI * 1e-3)]
        for angle in torch.deg2rad(torch.as_tensor(flip)):
            parts += [
                self.operators.excitation(angle),
                self.operators.readout(duration_s=TR * 1e-3),
            ]
        return parts

A model composing other simulators lists its properties in the class body and implements evaluate():

class JointRelaxometry(Simulator):
    properties = ("T1", "T2", "M0")

    def __init__(self, spgr_flip, ssfp_flip):
        self.spoiled = SPGRSimulator(TE=2.0, TR=6.0, flip=spgr_flip)
        self.balanced = bSSFPSimulator(TE=2.5, TR=5.0, flip=ssfp_flip)

    def evaluate(self, properties, **sequence): ...

Spin physics and event operators#

SpinPhysics declares the tissue properties of a voxel and the EventOperators that realize each kind of event. Any tissue property may be given to any simulator; giving one enables its term.

SpinPhysics

The tissue properties a model exposes and the operators that realize its events.

EventOperators

Operator factories, one per kind of event.

Operator tables#

A SpinPhysics takes one of four predefined EventOperators.

BALANCED

uncrushed

REFOCUSED

blochsim.model.SPOILED#

Operator factories, one per kind of event.

Each field is called with the protocol’s parameters for that event and decides which RfUse and EventAction its events carry. Assigning one selects, for example, a readout that winds the states on or a shaped excitation.
