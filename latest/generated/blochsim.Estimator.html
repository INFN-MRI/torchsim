Estimator#

class blochsim.Estimator(acquisition=None)[source]#

Bases: Module

Base class of the mapping methods.

fit() names the unknowns and draws the training set from acquisition; map() returns one named map per unknown. A new method subclasses this and implements _fit_arrays and _estimate_arrays, which see signals and parameters as matrices.

Parameters:

acquisition (Simulator, optional) – The sequence being inverted, with every property that is neither unknown nor measured separately already fixed. Omit to fit from signals.

fit(unknown=None, *, known=None, noise_std=0.0, rank=None, subspace=None, seed=None, samples=None, chunk=_CHUNK, signals=None, parameters=None, **ranges)[source]#

Fit the estimator over a sampling of the tissue it will meet.

Training signals are simulated from acquisition unless signals is given.

Parameters:

  • unknown (mapping, optional) – Properties to estimate, {name: (low, high)} to draw uniformly or {name: values} to use as given. Order sets the order of the maps. Equivalent to the keyword form; use it for a name that collides with a keyword of fit.

  • known (mapping or torch.Tensor, optional) – Properties measured separately, {name: range} or {name: values}; pass the measured maps again to map(). A tensor of columns when signals is given.

  • noise_std (float or torch.Tensor, optional) – Standard deviation of the noise added to training signals, in signal units (a fully relaxed voxel is 1). Default 0.

  • rank (int, optional) – Fit a temporal Subspace of this rank to the training signals and work in it. Not with subspace.

  • subspace (Subspace, optional) – Work in a basis fitted elsewhere. Not with rank.

  • seed (int, optional) – Seed of the training draw.

  • samples (int, optional) – Number of tissues to draw. Defaults to the length of any properties given as values, else 10000.

  • chunk (int, optional) – Samples simulated at a time. Default 4096.

  • signals (torch.Tensor, optional) – Training signals (samples, contrasts), used instead of simulating. map() then returns a tensor unless names were given.

  • parameters (torch.Tensor, optional) – Unknowns (samples, unknowns) accompanying signals.

  • **ranges – Unknown properties as keywords, as for unknown.

Returns:

This estimator, fitted.

Return type:

Estimator

Raises:

  • RuntimeError – If there are no signals and no acquisition to simulate them.

  • ValueError – If a name is both unknown and known, a range is not a pair, rank is not positive, or both rank and subspace are given.

  • chunk (int, optional) – Samples simulated at a time. Default 4096.

(signals, parameters, known); known is None when nothing is measured separately.

map(volume, known=None, *, uncertainty=False)[source]#

Estimate the tissue parameters of a measured volume.

Parameters:

  • volume (array-like) – Measurement (..., contrasts); every leading axis is a voxel axis and is kept on the maps.

  • known (mapping or torch.Tensor, optional) – Measured maps under the names given to fit(), each broadcast to the voxel shape.

  • uncertainty (bool, optional) – Also return the uncertainty of each map; see uncertainty_of(). Default False.

Returns:

{name: map} with the shape of volume without its contrast axis; a tensor of parameter columns if the estimator was fitted from arrays without names. With uncertainty=True, a (maps, uncertainties) pair.

Return type:

dict or torch.Tensor

Raises:

  • RuntimeError – If the estimator has not been fitted.

  • NotImplementedError – If the method states no uncertainty.

  • ValueError – If a measured map is missing or has the wrong voxel count.

forward(volume, known=None, *, uncertainty=False)[source]#

Alias of map().

uncertainty_of(volume, known=None)[source]#

Uncertainty of each map, as a standard deviation in the map’s units.

What it measures depends on the method. PERK states the learned total error, prior and noise together, rescaled to a standard deviation for a Gaussian error. NonlinearLeastSquares states the standard error from the inverse Fisher matrix at the solution, which is zero when the training noise is zero. Compare with crlb().

Parameters:

  • volume (array-like) – Measurement (..., contrasts), as for map().

  • known (mapping or torch.Tensor, optional) – Measured maps, as for map().

Returns:

One uncertainty per unknown, shaped like the maps.

Return type:

dict or torch.Tensor

Raises:

NotImplementedError – If the method states no uncertainty (DictionaryMatcher, LookupTable).

from_coefficients(coefficients, known=None)[source]#

Map coefficients already in this estimator’s basis.

Unlike map(), the input is not projected onto subspace first.

Parameters:

  • coefficients (array-like) – Subspace coefficients (..., rank); leading axes are voxel axes.

  • known (mapping, optional) – Measured maps, as for map().

Returns:

{name: map}, shaped like coefficients without its last axis.

Return type:

dict

Raises:

  • RuntimeError – If the estimator is unfitted or has no subspace.

  • ValueError – If the last axis is not the basis rank.
