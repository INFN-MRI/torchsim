SequenceDescription#

class blochsim.SequenceDescription(subsequence_index, tr_duration_us, events, rf_definitions, shim_definitions=<factory>, crusher_dephasing_rad=0.0, voxel_size_m=None, rf_raster_time_s=1e-06)[source]#

Bases: object

Event stream and RF resources of one repetition of a sequence.

The ratio crusher_dephasing_rad / voxel_size_m sets the b-factor diffusion is damped by and the phase each dephasing order acquires under flow; a zero dephasing leaves both out. voxel_size_m also sets the distance a moving spin crosses, which washes out the voxel; None declares no voxel, so spin velocity has no effect.

subsequence_index#

Index of this subsequence within a multi-part acquisition.

Type:

int

tr_duration_us#

Duration of one playing of the stream, in microseconds.

Type:

float or torch.Tensor

events#

Events in play order.

Type:

tuple of SequenceEvent

rf_definitions#

{id: RfDefinition} for the pulses the RF events name.

Type:

dict

shim_definitions#

{id: ShimDefinition} for the shims the RF events name.

Type:

dict

crusher_dephasing_rad#

Dephasing wound across one voxel by the unbalanced gradient, in radians.

Type:

float

voxel_size_m#

Voxel length the dephasing is wound across, in metres.

Type:

float, optional

rf_raster_time_s#

Dwell the RF shapes are sampled on, in seconds. Pulses are integrated against it.

Type:

float

classmethod from_operators(*parts, rf_definitions=None, shim_definitions=None, subsequence_index=0, crusher_dephasing_rad=0.0, voxel_size_m=None, start_s=0.0)[source]#

Build a description by laying operators out end to end.

Parameters:

  • *parts (Operator or tuple, optional) – Operators in play order, or (offset_s, operator) pairs.

  • rf_definitions (mapping, optional) – {id: RfDefinition}. One ideal pulse under id 0 when not given.

  • shim_definitions (mapping, optional) – {id: ShimDefinition}.

  • subsequence_index (int, optional) – Index of the subsequence within a scan.

  • crusher_dephasing_rad (float, optional) – Dephasing of one crusher across a voxel, in radians. Diffusion and flow are zero without it.

  • voxel_size_m (float, optional) – Voxel length the dephasing is wound across, in metres.

  • start_s (float or torch.Tensor, optional) – Start time of the first operator, in seconds.

Returns:

Lasting as long as the operators laid out end to end.

Return type:

SequenceDescription

classmethod from_pulseq(source, **settings)[source]#

Read one repetition of a Pulseq sequence.

Requires pypulseq (pip install blochsim[pulseq]).

Parameters:

  • source (str, Path or sequence) – A .seq file, or an in-memory pypulseq or pypulseqpp Sequence.

  • **settings – tr_index, subsequence_index, crusher_dephasing_rad and voxel_size_m, as for read_pulseq_description: tr_index is the repetition to read, in whole TRSize windows.

Return type:

SequenceDescription

Raises:

  • ImportError – If pypulseq is not installed.

  • ValueError – If the file declares no TRSize, tr_index is out of range, or the repetitions differ and none was named.
