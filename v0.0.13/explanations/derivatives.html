Derivatives#

TL;DR

  • Derivatives with respect to tissue properties are forward mode: jacobian(), one pass per property.

  • Derivatives with respect to sequence parameters are reverse mode: torch.Tensor.backward() on a cost built from the signal.

  • The Cramer-Rao bound and precision-driven sequence design are built on the Jacobian.

You ask for the derivative of the signal with respect to tissue properties to fit, map or bound them, and with respect to the sequence to design it. Both are computed by the same fused kernels that compute the signal.

Division of responsibility#

  • Derivatives beyond the second order. A third is refused rather than returned incomplete (a third derivative is refused, test_vjp.py).

  • Forward mode with respect to sequence parameters through jacobian(), and reverse mode through NumPy or CuPy inputs: a gradient belongs to a torch tensor (reverse mode still needs torch, test_array_backends.py).

  • A full Jacobian with respect to the sequence. Each reverse-mode pass gives the gradient of one scalar cost.

Method#

Forward-mode tissue derivatives#

Voxels are independent, so a tangent of ones along one property gives that property’s derivative in every voxel in one pass. The cost scales with the number of properties differentiated and not with the voxels or samples. The kernels carry a tangent beside each state value (dual arithmetic), so each operator is differentiated exactly rather than by finite differences.

Reverse-mode sequence derivatives#

A design cost is one number over tens to hundreds of flip angles. The adjoint kernel walks the event stream backwards over the states a forward sweep kept, and returns the gradient with respect to every flip angle, phase and duration together. No wrapper is needed: the engine reads which inputs require a gradient and selects the adjoint kernel.

Precision and the Fisher information#

For independent Gaussian noise of variance \(\sigma^2\) on the real and imaginary channels, the Fisher information is \(F = \operatorname{Re}(J^\mathsf{H} J) / \sigma^2\), with \(J\) the Jacobian of the signal, and crlb() returns the diagonal of \(F^{-1}\). A design that minimizes a bound therefore differentiates a Jacobian with respect to the sequence: forward mode inside reverse mode, both in the kernels.
